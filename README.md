# Прогноз оруденения на Анабарском щите: база знаний

Проект — в папке `BZ/`: локальная база знаний по рудной геологии. Сама находит
статьи, разбирает их на фрагменты с номерами страниц и отвечает:

- **Поиск** — фрагменты статей по смыслу и по точным словам (с синонимами из словаря);
- **Чат-бот** — ответ Qwen3 по статьям базы со ссылками на фрагменты;
- **Граф связей** — факты из статей с дословными цитатами, на своей вкладке;
- **Телеграм-бот** — то же в Телеграме, с картинкой связей.

| С чего начать | Файл |
|---|---|
| как поставить и запустить | `BZ/ЗАПУСК.md` |
| все команды и ключи | `BZ/docs/КОМАНДЫ.md` |
| как устроено внутри | `BZ/docs/УСТРОЙСТВО.md` |

Коротко:

```
cd BZ
python georag.py web --tg
```
