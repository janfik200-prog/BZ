# Прогноз оруденения на Анабарском щите: база знаний и база данных

В репозитории две части, каждая в своей папке и со своей инструкцией.

| Папка | Что это | С чего начать |
|---|---|---|
| `BZ/` | **База знаний** — сама ищет статьи, разбирает их на фрагменты, размечает по понятиям и отвечает на поиск | `BZ/ЗАПУСК.md` |
| `BD/` | **База данных проекта** (`gis_au_u`) — признаки, их паспорта, происхождение чисел и решения человека | `BD/db/README.md` |

## Как они связаны

Общее у двух частей — **словарь понятий**: в базе данных это справочник
`kb.concept`, в базе знаний — `BZ/vocabulary.yaml`, коды совпадают буква в букву.

```
признак (BD) → связь с понятием (BD) → понятие → фрагменты статей (BZ) → цитата, страница
```

1. В папке `BZ`: `python georag.py graph`, затем `python georag.py serve`.
2. В папке `BD`: `python scripts/db_kb_evidence.py --сухой` — посмотреть, что придёт;
   без `--сухой` — записать. Цитаты ложатся в обоснование паспортов черновиком.
3. Подтверждает человек в панели: `python -m gisdb.panel`.

Если части на разных компьютерах — SSH-туннель, см. раздел 6 в `BZ/ЗАПУСК.md`.

Перед первым запуском моста к рабочей базе нужно накатить миграции
`BD/db/sql/011_integrity.sql` и `012_kb_citations.sql` (от `gisadmin`).

Папка `BD` — копия репозитория github.com/Shlopa-alt/GIS-agent-db с двумя
добавленными коммитами (миграции 011 и 012, скрипт моста); история сохранена.
