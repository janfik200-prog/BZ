# ГеоRAG — база знаний по рудной геологии

Локальная база знаний для прогноза рудных узлов на Анабарском щите. Сама
находит статьи, разбирает их на фрагменты с номерами страниц и отвечает:

- **Поиск** — фрагменты статей по смыслу и по точным словам, русский запрос
  находит и английские статьи;
- **Статьи** — всё, что разобрано, с разбором по фрагментам;
- **Чат-бот** — ответ Qwen3 по статьям базы, с номером фрагмента после каждого
  утверждения. Ищет вместе с моделью: Qwen3 разбирает сложный вопрос, читает
  найденное, берёт подходящее и ищет недостающее. Если в базе такой информации нет, бот так и пишет
  и отвечает из общих знаний модели — с пометкой, что это не из базы. На
  своей вкладке — граф знаний, как в Obsidian, с поиском узла.

Граф знаний — факты из статей: «Билляхская зона — входит в — Анабарский щит»,
с дословной цитатой. Выписывает их Qwen3 по правилам `config/graph-rules.txt`,
код проверяет каждый: цитата должна быть в статье, а в цитате — оба конца.
Разные написания одного и того же сводит словарь синонимов
`config/synonyms.yaml`; пополнять его помогает модель, решает человек.

У любой сущности графа есть датасет — все факты о ней с цитатами и статьями:
`python georag.py dataset "Анабарский щит"`.

Качество поиска и ответов проверяется набором вопросов: `python georag.py eval`.

То же — в Телеграме: `python georag.py web --tg` (страница и бот сразу).

Всё работает на одной машине: PostgreSQL с pgvector в Docker, BGE-M3 для
векторов, Docling для разбора PDF, Qwen3 через Ollama.

```
python georag.py web
```

## С чего начать

| Файл | Что там |
|---|---|
| **`ЗАПУСК.md`** | как поставить и запустить, по шагам |
| `docs/КОМАНДЫ.md` | все команды, ключи и тонкие настройки |
| `docs/УСТРОЙСТВО.md` | как устроено внутри |

## Что где лежит

```
georag.py       вход для всех команд: python georag.py help
config/         темы поиска, источники, правила графа, синонимы, вопросы оценки — правится Блокнотом
georag/         код: acquire · parse · index · graph · chat · web · evaluation
                общее: llm (Ollama) · text (русский текст) · common (ключи команд)
tests/          проверки, эталоны разбора, тестовый корпус
docs/           справочник и устройство


Сами PDF на диск не сохраняются: остаются ссылка, отпечаток файла и
разобранный текст.
