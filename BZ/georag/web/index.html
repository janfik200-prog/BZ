    Строгость отсекает «ближайшее, но не по делу»: вектор всегда находит что-нибудь, даже когда в базе нет ничего подходящего. Куски, где буквально есть все слова запроса, проходят порог всегда — совпадение по словам само по себе доказательство.

    Подпись у каждого результата говорит, кто его нашёл: вектор — по смыслу, текст — по точным словам, оба — сошлись оба способа.

    Связь означает одно: об этих двух написано в одной статье. Ничего не додумано — за каждой связью стоит список статей, который можно открыть и прочитать. Названия достаются правилами по опорным словам («…ский рудный узел», «…ское рудопроявление»), поэтому объекты с обратным порядком слов — «трубка Удачная» — пока не попадают в список.
