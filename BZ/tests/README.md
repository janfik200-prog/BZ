# Проверки достоверности

Без базы и модели:

```powershell
.venv/Scripts/python.exe -m unittest discover -s tests
```

С работающими PostgreSQL, BGE-M3 и vLLM, из корня проекта:

```powershell
.venv/Scripts/python.exe tools/trace_retrieval.py --output .local/trace.json
```

`grounded_cases.json` — начальный набор из двух фактов одной статьи, не оценка
качества всего корпуса. Эталон определяется статьёй, порядком фрагмента и цитатой;
идентификатор chunk_id определяется при запуске. Соседний фрагмент устанавливает
географический контекст. При изменении текста проверка цитаты останавливает запуск.

Трасса сохраняет выдачу каждого запроса, слияние, кандидатов и ответы отборщика,
принятые и выбранные фрагменты, контекст после сокращения и ответы модели.
Контрольный ответ получает правильные фрагменты напрямую. Сбор выписок и проверка
противоречий отключены в обоих режимах, остальные настройки стандартные. Запись
в базу не требуется; результаты пишутся в указанный файл после каждого вопроса.

`terms_present` проверяет только наличие слов, а не смысл, отрицание, направление
отношения или правильность ссылки. Ответы и номера источников нужно просматривать.
Попадание эталонного chunk_id не гарантирует наличие всей цитаты в обрезанном
контексте; соседние фрагменты также могут содержать продолжение с нужным фактом.
Отсутствие chunk_id среди кандидатов ещё не доказывает отсутствие других подходящих
источников. Случаи без сведений в корпусе пока проверяются отдельными HTTP-прогонами.
