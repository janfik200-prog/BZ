# До модели код ищет во фрагменте предметы: эти термины, имена собственные и места
# (spaCy). Фрагмент, где не нашлось ни одного, модели не отдаётся — из таких
# фрагментов она фактов почти не выписывала. Найденное уходит модели списком: она
# только определяет связи между ними.
#
# Один термин в строке, русский или английский. Падеж и число не важны: «кварц»
# находит «кварца», «кварцем» (но не «кварцевых» — это другое слово, его пишут
# отдельно); английский — и во множественном числе. Строки с # — комментарии.
# Правится Блокнотом, сохранять в UTF-8. Действует со следующего запуска graph.
