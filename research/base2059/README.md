# Проверка объяснимости на базе из 2 059 статей

База — коллекция по геологии золота (2 059 публикаций, 114 229 фрагментов, граф 50 829 связей,
построенный Qwen3-14B 22–23.10.2026; 1 053 связи — пробный проход Qwen3-8B). Все расчёты только
читают базу (`GEORAG_DSN`, порт 5435); граф не перестраивался. Сводка, выводы и что исправить —
`Находки_и_исправления_база2059.docx`.

## Где какие метрики

| Что | Файл | Скрипт |

| Граф: модели, подтверждённые и по повтору, типизация, изменённое кодом направление, пары в ≥ 2 публикациях, темы Лейдена (Q, NMI) | `results/graph_metrics.json` | `base_metrics.py` |
| Прослеживаемость (цитата, страница, раздел, DOI), территория связи и её источник, прозрачность (причины отказов кода), выборка 2 000 связей графа | `results/summary.json`, `results/report.md`, `results/facts.csv` | `trace_sample.py` |
| Ручная разметка: связи, виды ошибок, оговорки | `results/links_scores.json` | `score.py` |

## Разметка

- `Разметка_база2059_проверено.xlsx` — связи, фильтр, типизация, отрицания, модальность (ключ — `key.json`).
- `v18/Разметка_сравнение_main.xlsx` — слепая разметка двух способов выделения.
- `qa/Вопросы_набор1.xlsx` — годность вопросов для оценки поиска.

## Отчёт и рисунок

- `edit_report.py ИСХОДНЫЙ.docx НОВЫЙ.docx` — отчёт НИР с числами этой базы.
