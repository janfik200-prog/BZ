# Выборка для оценки словарного фильтра: совокупность, отбор, исключения

Документ собирается скриптом `reports.py` из `results/corpus_structure.json` и `results/labeling_scores.json`.

## Что было не так в v16

Выборку для разметки `labeling_sheet.py` отбирал только из фрагментов длиной от 200 знаков (`len(c["text"]) >= 200`). При этом доли переносились на все фрагменты, кроме дубликатов и подписей, без ограничения длины (`filter_population`). Короткие фрагменты не могли попасть в разметку, но участвовали в расчёте полноты. В коде системы (`facts.run`) правила о длине нет: короткий фрагмент проходит фильтр так же, как длинный.

## Структура корпуса

Признаки пересекаются, поэтому фрагменты разложены по комбинациям: каждый фрагмент считается один раз.

| Комбинация признаков | Фрагментов |
|---|---|
| обычные | 4009 |
| короткие (< 200 знаков) | 123 |
| подписи и легенды | 120 |
| подписи, короткие | 14 |
| дубликаты | 6 |
| **всего** | **4272** |

- Дубликатов (MinHash, `dedup.py`): 6. Подписей и легенд (`captions.py`): 134. Короче 200 знаков: 137, из них 14 — подписи.
- **Область применения фильтра** — не дубликаты и не подписи: 4132 фрагментов. Дубликаты и подписи отсеиваются другими правилами при любом пороге.
- **Рамка выборки v16** — область без коротких: 4009 фрагментов.
- **Короткие фрагменты области**: 123 (3,0 % фрагментов, 0,4 % токенов). Связи графа есть в 1 из них, записанные связи — в 2.

## Способ отбора и оценки

1. **Рамка.** Из 4009 фрагментов отобрано 150: по 25 из каждой группы по числу терминов словаря (0, 1, 2, 3, 4, 5 и больше), зерно 20261031. Разметчик не видел числа терминов и извлечённых связей.
2. **Размечено 149 из 150.** Строка 36 (фрагмент 4175, терминов 3) оставлена автором пустой с пометкой «Повреждённая геохимическая таблица: нельзя уверенно восстановить соответствие проб, элементов и значений». Оценка неоднозначна, поэтому строка в расчёт не входит, ни 0, ни 1 ей не присваивается. В группе «3 термина» — 24 ответа.
3. **Веса страт исправлены.** Доля фрагментов со связями в группе переносится на численность группы **в рамке**, а не во всей области. Так вывод относится к той совокупности, из которой бралась выборка.
4. **Короткие фрагменты** (все 123) размечаются сплошь, по тому же правилу: лист «Короткие» в `Разметка_v17_проверено.xlsx`. У сплошной разметки нет ошибки выборки, и оценка для всей области — сумма двух страт. Размечено 123 из 123, со связями — 14.
5. **Интервалы** — бутстрэп внутри страт, 10 000 повторов, зерно 1, перцентили 2,5–97,5 %.

## Два разных показателя полноты

| | Ретроспективная проверка (v15) | Ручная разметка (v16–v17) |
|---|---|---|
| Что считается | доля **связей уже построенного графа**, лежащих во фрагментах, которые порог 3 отсеял бы | доля **фрагментов, где по разметке есть геологическая связь**, которые порог 3 отсеял бы |
| Знаменатель | связи графа (3 818) | фрагменты со связями (оценка по выборке) |
| Значение | 1,8 % | 9,3 % (рамка) |

Эти числа не противоречат друг другу и не опровергают одно другое: у них разные знаменатели. Граф строился по фрагментам, где модель смогла извлечь и подтвердить связь. Во фрагментах с малым числом терминов таких связей мало, даже если сама связь в тексте есть. Поэтому ретроспективная проверка по графу показывает, сколько уже найденного потерял бы фильтр, но не измеряет пропуск всех связей, которые можно было бы извлечь. Это видно и по охвату: связи графа есть примерно в 46,1 % фрагментов, где по разметке есть связи.
