# Ограничения v17

## Предварительный фильтр

- **Оценка относится к фрагментам длиной от 200 знаков** (рамка выборки: 4 009 из 4 132 фрагментов области фильтра). 123 коротких фрагмента (3,0 % фрагментов, 0,4 % токенов) в выборку v16 не входили.
  - Для них подготовлен лист сплошной разметки «Короткие» в `Разметка_v17.xlsx`.
  - Пока он не размечен, для всей области даны только границы полноты: при пороге 3 — от 0,874 до 0,907.
  - После разметки `labeling_score.py` сам перейдёт к оценке для всей области. Подробно — в `prefilter_sampling_audit.md`.
- **Оценка по фрагментам, а не по отдельным связям, одним разметчиком.** Группы по 25 фрагментов дают широкие интервалы, до ±0,2 на группу.
- **Одна строка из 150 не размечена** (повреждённая таблица). Она не считается ни 0, ни 1.
- **Экономия токенов по порогам оценена по длине фрагментов.** Прямой замер есть только для порога 3 на 100 фрагментах: 21,3 %.
- **Охват графа (около 46 % фрагментов со связями) оценён по 67 фрагментам со связями** и только для рамки; интервал 0,29–0,62.

## Подтверждение, типизация и граф

- **53 связи графа приняты по повтору и не типизированы** (`graph_typing_invariant.md`).
  - 31 из них подтверждают только друг друга.
  - 10 — повтор между препринтом и опубликованной версией одной работы.
  - Система не исправлялась: это изменение рабочего кода. В статье v17 число типизированных связей (3 765) и троек (3 738) указано отдельно.
- **Повторная типизация 53 связей выполнена моделью через vLLM** (Qwen3-14B-AWQ), а не той же установкой, что исходная типизация. Ответы могут отличаться. Ручная оценка этих связей — лист «Без типизации» в `Разметка_v17.xlsx` — пока не выполнена.
- **3 585 связей исключены типизацией.** По разметке 60 из них 33 исключены напрасно (0,55; интервал 0,42–0,67). Этап не исправлялся.
- **22 218 предложенных и 8 479 отклонённых связей — нижние границы.** Причины три:
  - лимит журнала в 40 строк на фрагмент;
  - повторы внутри фрагмента не записываются;
  - разбор фрагмента прекращается после 20 связей — так было у 193 фрагментов.

  Сколько связей потеряно из-за двух последних причин, по базе восстановить нельзя (`relation_count_definitions.md`).
- **Воронка описывает текущее состояние `georag_v14`.** Состояния после ранних прогонов не сохранялись.

## Извлечение

- **Точность — по 120 связям графа и одному разметчику** (автору). Согласие разметчиков не измерялось.
- **Расширенное правило предположений** подобрано по тем же 120 связям. На новых связях его точность 56 из 98 (0,57). Полнота не измерялась.
- **Отрицания проверены только на связях графа,** где отрицание есть в цитате, но не в связи: 83 из 85 размеченных верны.
- **Извлечение с полями modality и polarity не проводилось.** Нужен новый проход модели и разметка.

## Поиск

- **Оба набора вопросов составлены моделью по фрагментам тех же статей.** Это проверка поиска известного источника.
- **Релевантной считается только исходная статья.** Другая статья о том же объекте, например препринт той же работы (вопрос set89-91), засчитывается как ошибка. Поэтому графовые и территориальные варианты, поднимающие другие релевантные статьи, штрафуются.
- **B3 против B2t:** 3 исправления, 0 ухудшений из 173. Превосходство не установлено: интервал 0,00–0,04, p = 0,25. Признаки случаев (транслитерация, неявное место и т. д.) размечены автоматически по написаниям, а не человеком.
- **Признаки «граф помог / помешал»** выведены по выдаче. Верность связей в 16 случаях ухудшения оценена по их тексту при разборе, отдельной независимой разметки нет.
- **Другие веса RRF и схемы объединения не проверялись,** чтобы не подбирать параметры по тестовым вопросам.
- **Поиск без 53 нетипизированных связей (вариант графа B) не пересчитывался.**
