## Результаты повторного запуска

- **Воронка связей и ошибки извлечения.** `relation_pipeline_summary.json`, `relation_pipeline_audit.csv`, `extraction_errors.csv`, `extraction_modality.json` побайтно совпали с опубликованными в v16.
- **Поиск.** Все метрики 173 вопросов и все парные интервалы бутстрэпа совпали с v16 (`retrieval_summary.json` без полей времени). Различается только время выполнения (`seconds_median`): оно зависит от загрузки машины.
- **Разметка.** Доли типизации (0,55), отрицаний (0,976) и модальности (0,571) совпали. Оценки фильтра изменились из-за исправления методики (ниже).
- **Таблицы и рисунки** пересобираются из JSON и CSV без ручных правок.
- **База.** Отпечаток таблиц `facts`, `facts_pass`, `chunks`, `documents` (`results/db_fingerprint.json`) после всех шагов совпал с сохранённым. Ни один скрипт v17 не содержит команд записи в базу.

Отпечаток снят в ходе работы над v17, после первых шагов. Они только читали базу, поэтому это отпечаток исходного состояния.

## Автоматические проверки (`checks.py`)

Все 22 проверки пройдены (`results/checks.json`):

- **Согласованность файлов:** числа CSV и JSON сходятся (воронка, фильтр, поиск, парный разбор).
- **Пропуски в разметке:** пустые ответы не считаются размеченными.
- **Знаменатели:** сумма страт равна числу размеченных, доля равна k/n.
- **Группы:** нет пустых страт.
- **Стадии воронки:** 13 739 = 3 818 + 6 336 + 3 585; 53 = 3 818 − 3 765.
- **Короткие фрагменты:** оценка для всей области не выдаётся без их разметки.
- **Статья:** числа разметки и ключевые показатели совпадают с JSON, рабочих пометок нет.
- **Исторические данные:** база не изменилась.
