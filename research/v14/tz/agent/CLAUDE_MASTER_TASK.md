## Точные задачи и порядок зависимости

**B. Контракт доказательства.** Реализуй EvidenceSpan и GeoClaim, QueryFrame, SupportAssessment, DecisionRecord с проверкой JSON-схем; source SHA, parsed SHA, точный quote span и page. Не прячь битые цитаты. Миграции БД с rollback, старые данные сохраняются.

**C. Двухэтапное извлечение.** Сначала воспроизведи старое извлечение E0, потом добавь высокополнотный MinHash LSH + NER + словарь без изменения LLM (E1), затем отдельно снизь размер builder до Qwen3-8B (E2). Защити отрицания, места, числа, модальность и разные районы от удаления по MinHash. Порог `k` выбери только на DEV. Оставляй все решения фильтра в JSONL, включая отброшенные фрагменты.

**D. Source support.** Сохрани существующую четвёрку вопросов как измеряемый baseline. Отдельно проверяй смысл отношения, направление, отрицание, предположение, квантор, отсутствие утверждения при простом совместном упоминании. Четыре ответа одной модели не являются независимыми голосами. Не разрешай `facts_pass`/буферу реанимировать неподтверждённое отношение по одному совпадению источников.

**E. Новая научная реализация.** Реестр географических объектов с доказанной вложенностью, нормализацией названий и источником каждого alias. Контекст по цитате/параграфу/заголовку с отдельными source spans; название обзорной статьи не достаточно для DIRECT. Кодовые ограничения по территории, типу минерализации, модальности, полярности, квантору. Построй чистую функцию `decide_applicability`; statuses DIRECT/ANALOG/OUT_OF_SCOPE/UNRESOLVED и `reason_codes`. Используй 10 инвариантов из ТЗ.

**F. Конфликты и независимость.** Отличай обзор от первоисточника, противоречие от другого района/стадии. Не объединяй топонимы по одному embedding similarity 0.95.

**G. Интеграция.** Подключи gate к GraphRAG и цитатной сверке чата. Если проверяется лишь 24 утверждения, маркируй остальные NOT_CHECKED. **H. Независимая оценка.** На небольшом *реальном* корпусе (ориентир 25–40 разрешённых документов, 120–200 пар факт-вопрос) подготовь разметку support + applicability. Делить по документным семействам/первоисточникам, не по чанкам. По возможности независимая проверка геологом; при отсутствии эксперта не выдавай модельные метки за gold. Синтетические fixtures — только тесты политики, не показатели статьи.

**I. Исследование.** Выполни E0/E1/E2 (стоимость и потери), V0/V1/V2/V3 на ОДНОМ списке фактов/вопросов (региональная применимость), P0/P1/P2/P3 (сквозные ответы), абляции, ошибки. Публикуй raw JSONL, не только красивую таблицу.

**J.
