# DECISIONS — решения, принятые при исполнении ТЗ v13 → v14

Каждое решение — что выбрано, почему, чем рискуем. Хронологически.

1. **Не переписывать систему.** Новый код — пакет `georag/evidence/` рядом с графом и
   чатом; старые `facts.py`, `confirm.py`, `kinds.py`, `store.py` не менялись. Встраивание —
   две функции-обёртки (`chat/dataset._scope_gate`, `chat/answer` → `gate.filter_sources`)
   под флагом `GEORAG_SCOPE_GATE=1`; без флага поведение боевой системы прежнее (тест
   `test_gate_off_by_default`). Изменён по существу только `chat/support.py` + `answer.py`:
   событие ответа получило поле `not_checked` (утверждения сверх лимита 24).
2. **Боевая база не менялась.** Резервная копия `pg_dump` и копия `georag_v14`; все скрипты
   читают `GEORAG_DSN` и пишут только в файлы `research/v14`.
3. **Схемы.** Контракты v13.1 — как в пакете ТЗ; добавлена надстройка v14 (необязательные
   поля: стадия/масштаб вопроса, модальность/полярность/основание области в решении).
   Объект без новых полей пишется как v13.1.
4. **Нормализация цитаты** одна: схлопывание пробельных знаков. Смещения — в нормализованном
   тексте фрагмента; `parsed_sha256` — по нормализованным фрагментам статьи. Причина: цитаты
   графа собраны из предложений `split_sentences`, а не байтовым срезом.
5. **Отпечаток PDF не выдумывается.** Нет корректного `sha256` в базе — поле пусто, и
   доказательство не проходит (`PDF_HASH_MISSING`). Версия парсера в базе не записана —
   `docling@unrecorded`.
6. **Справочник территорий** собран вручную (агентом) из кандидатов-топонимов корпуса и
   названий статей **до** формирования выборки; 197 единиц, 744 написания. Основание каждой
   связи включения: `SOURCE` (название/текст статьи корпуса), `ADMIN`, `GEOLOGY`. Внутренние
   id `R:…`; официальные коды не проставлены (нет проверенного источника). Две известные
   территории без записанной вложенности — `DISJOINT`, если не записано перекрытие
   (`overlaps`, например Восточная пустыня ↔ Аравийско-Нубийский щит). Одноимённые
   «Майское» (Чукотка и Северная Карелия) — два id, неоднозначность снимается только
   вложенностью с другой названной территорией.
7. **Порядок контекста:** цитата → анафора с явной ссылкой (1–2 предложения назад) →
   заголовок раздела без конфликта с фрагментом → название статьи, только конкретное
   (одна территория, не обзор) и без конфликта. Общий/обзорный заголовок —
   `REGION_TITLE_ONLY` (не DIRECT). Это закрывает заглушку v13 «порядок источников».
8. **Аналогия** — только при общем теге обстановки в справочнике (`settings`, с учётом
   предков) **и** подтверждённой совместимости типа оруденения у факта и вопроса.
   «Тот же металл в чужом районе» без общей обстановки — `OUT_OF_SCOPE` + `ANALOGY_NOT_GROUNDED`.
9. **Квантор.** Для вопроса `TYPICAL/ALL` прямой ответ даёт только факт о той же территории
   (не о части) с квантором `TYPICAL/ALL`; факт о части — DIRECT лишь для существования.
   Факт о более широкой территории — `REGION_CONTAINS_TARGET` (не DIRECT).
10. **Гипотеза** — DIRECT только для вопроса о гипотезах (`RESEARCH_REVIEW`), с сохранённой
    `HYPOTHESIS`; отрицание — DIRECT только для вопроса об отсутствии.
11. **Разметка.** Геолога нет; разметку выполнил один разметчик — Claude (модель, которая
    не выписывала и не подтверждала факты системы), по правилам, зафиксированным до
    разметки, вслепую к предсказаниям методов, с заморозкой отпечатков (`FREEZE.json`) до
    прогона. Это пилотная, не экспертная разметка: научные выводы — предварительные.
    Подготовлен пакет для слепой проверки геологом (164 пары, 49 %).
12. **Выборка.** Пары — из боевого графа, как их выдал бы граф без контроля контекста;
    стратификация — по вручную заданной области исследования статей (метаданные
    разметки, не вывод кода). Дополнение (+72 пары) сделано после первой разметки, до
    прогона методов: DIRECT-пар было 33 (< 35 по ТЗ), кандидатов в аналоги — 0.
13. **DEV/TEST** — по семействам источников (`sha256('v14-split|'+family) mod 100 < 35`).
    Семейства: почти-дубли фрагментов, серия «Часть I/II» одной команды, версии одной
    работы (та же команда, близкое название) — найдены 2 реальные пары.
14. **Предрегистрация.** Политика v14.1 и порог голосов 3 заданы до прогона; TEST-итог для
    них — основной. Правило объединения поддержки (`votes≥1 И модель=ENTAILED`) выбрано
    **на DEV** по критерию, записанному в скрипте до прогона; на TEST применено один раз и
    отчитывается отдельно как вторичный протокол.
15. **Порог `k` первого этапа** выбирается на DEV: наибольший `k`, при котором теряется
    ≤ 5 % опорных фактов E0 (критерий записан в `run_e.py` до прогона).
16. **E2 (Qwen3-8B).** Живой прогон требует остановить модель ответов (на 16 ГБ обе не
    помещаются) — это изменение работающего сервиса; без разрешения не делалось. Для E2
    использованы исторические прогоны `georag_b14`/`georag_b8v3` с оговоркой о версиях правил.
17. **Повтор текста** (дословно та же цитата в разных статьях) — один голос, даже при
    разных семействах (найдено на двух статьях одной группы авторов о Судане).
18. **Эвристика сбоя OCR** сужена до букв через пробел (ряд цифр таблицы — не сбой) после
    аудита всего графа; на выборку эксперимента V это не влияет (все 335 цитат проходили).
